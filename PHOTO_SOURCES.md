# Sources provisoires des visuels

## Usage actuel

Les visuels présents dans `public/images/real/` servent à produire une maquette crédible et à valider la direction artistique avec le propriétaire. Leur présence dans le dépôt ne constitue pas une validation définitive des droits de publication.

## Limitation Instagram

L’accès automatisé aux fichiers médias du compte Instagram a été bloqué par la plateforme pendant la préparation du prototype. Les visuels publics accessibles depuis les fiches de l’établissement ont donc été utilisés temporairement afin de ne pas livrer un site vide.

Avant mise en ligne :

1. demander au propriétaire le dossier original du shooting Instagram ;
2. confirmer par écrit qu’il peut utiliser ces images sur son site ;
3. remplacer les fichiers sans changer leurs noms, ou mettre à jour `src/content/gallery.ts` ;
4. vérifier les crédits et le droit à l’image ;
5. valider que le menu photographié est toujours actuel.
