# Images du prototype de L’Authentique

Le prototype utilise désormais de vrais visuels publics de l’établissement pour rendre la direction artistique immédiatement compréhensible : façade, terrasse, équipe, plats, cuisine, ambiance du soir et menu.

## Important avant publication

Ces fichiers ont été intégrés à titre de **maquette fonctionnelle** à partir de pages publiques consacrées à l’établissement. Ils doivent être remplacés par les fichiers originaux transmis par le propriétaire ou le photographe avant la mise en production définitive.

À vérifier avec le propriétaire :

- autorisation d’utilisation sur le site officiel ;
- identité et crédit du photographe ;
- présence éventuelle de personnes reconnaissables ;
- disponibilité des originaux non compressés ;
- actualité du menu photographié.

Les photos Instagram ne doivent pas être récupérées par capture d’écran lorsque les originaux existent. Instagram compresse fortement les médias. Le dossier final doit idéalement provenir du téléphone du propriétaire, de Google Drive ou du prestataire photo.

- `real/paella.webp` : plat collectif ;
- `real/bar-night.webp` : comptoir le soir ;
- `real/equipe.webp` : équipe au comptoir ;
- `real/cuisine.webp` : préparation en cuisine ;
- `real/menu-recto.webp` et `real/menu-verso.webp` : carte publique datée de 2024 ;
- `brand/logo-authentique.webp` : logo temporairement extrait du menu public.

## Formats recommandés pour les remplacements

- hero : ratio 3/2 ou 16/9, 2000 à 2600 px de large ;
- plats : ratio 4/3, au moins 1400 × 1050 px ;
- portraits et équipe : ratio 4/5 ou 3/2 ;
- galerie : au moins 1600 px sur le grand côté ;
- logo : SVG ou PNG transparent ;
- Open Graph : 1200 × 630 px.

Formats Web conseillés : AVIF ou WebP, avec les originaux conservés séparément.
