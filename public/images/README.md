# Médias de L’Authentique

Les médias utilisés par le site proviennent du dossier Drive transmis par le client le 30 juillet 2026. Seuls les fichiers effectivement affichés ont été convertis en WebP et conservés dans le dépôt.

## Organisation

- `brand/` : logo horizontal officiel fourni par le client ;
- `hero/` : visuels desktop, mobile et Open Graph ;
- `menu/` : carte recto et verso issue des fichiers HEIC client ;
- `location/` : façade, terrasse, bar et accueil ;
- `food/` : plats utilisés dans les mises en avant et la galerie ;
- `drinks/` : cocktail et bière utilisés dans les mises en avant et la galerie.

Les fichiers bruts HEIC, JPG, PNG et PDF restent en dehors du dépôt.
